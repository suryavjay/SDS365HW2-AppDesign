Image Compression App

I wanted a simple way to upload an image, change the number of components, and see how the result compares with the original.

Open the Shiny app

How I would use it

I would put the upload button at the top left so it is easy to find. Someone could choose their own image using the Browse button. A sample image would already be there when the app opens, so they could try the controls right away.

The slider would go right below the upload button. It would let people choose a whole-number value of k, from 1 to the smaller image dimension. Moving it to the left would keep fewer components, and moving it to the right would keep more detail. The compressed image would update automatically, without needing another button.

I would put the original on the left and the compressed version on the right, with both shown at the same scale. That would make it easier to spot which details disappear at a smaller k. The current k and the error values would appear below the images. On a small screen, the controls and images would stack vertically.

About the images

The app would accept common image formats such as PNG and JPG and show them in grayscale, like the images used in the homework. Large images would be resized to fit within 600 by 600 pixels before doing PCA so the app stays responsive. Both previews and the error calculation would use that same grayscale image. The maximum upload size would be 15 MB.

The relative error would show the Frobenius error divided by the norm of the original image, written as a percentage. A smaller error means the approximation is closer to the original. I would use the previews along with the error to decide when the image looks good enough.
